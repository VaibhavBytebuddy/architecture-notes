# Architecture & Engineering Documentation

This directory contains technical references, system architecture overviews, and developer roadmaps for Java Full-Stack, event-driven pipelines, and distributed services.

### Contents:
- **`roadmap.html`**: Interactive mindmap overview of Java Core, Spring Boot, event-driven architecture, and system concepts.
- **`engineering_guide.pdf`**: Complete printable system architecture and engineering guide.
- **`SYSTEM_ARCHITECTURE_SUMMARY.md`**: Platform architecture breakdown, service boundaries, and technical case studies.
- **`build_docs.py`**: Python script to generate the engineering documentation.
